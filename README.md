# Юридичний порадник · Veritas MV

Статичний сайт адвокатського об'єднання Veritas MV (HTML + CSS + JS, без збірки й залежностей).

- Головна сторінка: `index.html`
- Попередній перегляд для iPhone / ПК: `preview.html`
- Налаштування форми заявок: `js/config.js` (поле `formEndpoint`)
- Домен у canonical, sitemap.xml і robots.txt: `https://veritasmv.com.ua`

Публікується через GitHub Pages (гілка `main`, коренева папка).
